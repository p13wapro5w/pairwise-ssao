# pairwise-ssao

墙角和环境接触的地方总有一圈脏影：SSAO 半球核固定在世界空间，相机一转采样方向跟着转，遮蔽像贴不住；噪声纹理按屏幕平铺，移动时出现明显重复；深度重建用线性深度但没处理远平面，远处遮蔽全黑；多相机各自生成 AO，分屏接缝处亮度不一致；TAA 把 AO 当颜色一起累积，运动物体边缘拖出灰边；双边滤波只按深度，法线不同的墙和地板被糊在一起；半分辨率 AO 上采样用最近邻，边缘出现方块；透明物体写深度，AO 把它当实体遮住背景；远距离遮蔽强度没衰减，天空盒边缘发黑；异步 compute 与主渲染没同步，AO 偶尔晚一帧。render/ssao.py 是核心，tests/test_ssao.py 15 个红。要修的是：相机空间核；噪声去重复；远平面重建；相机 AO 隔离；时域分离；法线双边；自适应上采样；透明剔除；距离衰减；compute 同步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
